Docker または Kubernetes を使用して、自社のインフラストラクチャに Sim Studio をデプロイします。

## 要件

| リソース   | 最小      | 推奨       |
| ---------- | --------- | ---------- |
| CPU        | 2 コア    | 4+コア     |
| RAM        | 12 GB     | 16+ GB     |
| ストレージ | 20 GB SSD | 50+ GB SSD |
| Docker     | 20.10+    | 最新版     |

## クイックスタート

```bash
git clone https://github.com/.git && cd sim
docker compose -f docker-compose.prod.yml up -d
```

[http://localhost:5863](http://localhost:5863)を開く

| コンポーネント | ポート | 説明                                         |
